# telc B2 Mündliche Prüfung Trainer • Kerala Edition
### 🇩🇪 German • 🇮🇳 മലയാളം • 🇬🇧 English

A dedicated, authentic **telc Deutsch B2 Oral Exam Preparation Web Application** designed specifically for **B2 students and healthcare professionals (nurses, caregivers, and graduates) in Kerala** preparing for their telc B2 Mündliche Prüfung in Germany.

---

## 🌟 Key Features

### 1. 👩‍🏫 Live Interactive telc B2 Examiner Simulation (Frau Dr. Weber)
- **Authentic Examiner Persona**: Delivers prompts, listens attentively, and asks realistic telc follow-up questions (*Prüferfragen*).
- **🤖 Real AI Speaking Session Analysis**:
  - **100% Free Google Gemini Integration** (Gemini 2.0 / 1.5 Flash via Google AI Studio).
  - Also supports Groq (Llama 3.3) and OpenAI (GPT-4o-mini).
  - Evaluates speech against the official 4 telc B2 criteria: *Aufgabenbewältigung*, *Ausdrucksfähigkeit*, *Formale Richtigkeit*, *Kohärenz & Flüssigkeit*.
  - **Themaverfehlung Detection**: Automatically alerts candidates if they speak off-topic.
  - **Interactive Grammar Corrections**: Side-by-side diffs showing student errors, B2 corrections, and specific Malayalam explanations for South Asian language structures.
  - **B2 Expression Upgrades**: Upgrades simple German words to formal B2 idioms and collocations (*Nomen-Verb-Verbindungen*).
  - **Dynamic Follow-Up Questions**: AI Prüfer generates personalized contextual follow-up questions based on what the candidate spoke.
- **Speech Synthesis (German TTS)**: Native German audio with adjustable speed (0.8x slower for comprehension, 1.0x normal, 1.15x exam pace).
- **Voice Input (Speech-to-Text)**: Speak directly into your microphone in German to simulate live exam speaking.
- **Audio Recording Studio**: Record your 3-minute presentations and listen back to practice your pronunciation.
- **Trilingual & Flexible Language Modes**:
  - `🇩🇪 + 🇮🇳 മലയാളം + 🇬🇧 English`: Full trilingual support.
  - `🇩🇪 + 🇬🇧 English Only (No Malayalam)`: Pure German exam preparation with full English guidance (ideal for all international students).
  - `🇩🇪 + 🇮🇳 മലയാളം Focus`: Prioritizes Malayalam explanations for Kerala nurses and learners.
  - `🇩🇪 Nur Deutsch (Immersion)`: Strict exam simulation mode with all translations hidden.

### 2. 🗣️ Teil 1: Präsentation (3 Minuten)
- Authentic topics: *Eine Reise, die Sie beeindruckt hat*, *Ein Buch*, *Ein Film*, *Eine wichtige Person*, *Berufsausbildung im Pflegebereich*.
- Structured outlines: *Einleitung*, *Hauptteil*, *Eigene Meinung*, *Zusammenfassung*, and *Prüferfragen*.
- Dual Malayalam & English translations for every prompt and sample answer.

### 3. 💬 Teil 2: Diskussion (5 Minuten)
- Controversial B2 topics: *Vier-Tage-Woche*, *Bargeldlose Gesellschaft*, *Tempolimit auf Autobahnen*.
- Reading texts (*Lesetexte*) with audio narration.
- Categorized **Pro & Contra arguments** with Malayalam translations.

### 4. 🤝 Teil 3: Problemlösung / Gemeinsam planen (5 Minuten)
- Realistic workplace & hospital scenarios: *Abschiedsfeier für eine Kollegin organisieren*, *Betriebsausflug planen*, *Tag der offenen Tür im Gesundheitszentrum*.
- Collaborative checklists (*Wann, Wo, Wer, Budget, Aufgabenverteilung*).

### 5. 📖 B2 Redemittel Vault
- High-scoring standard phrases categorized by exam parts with one-click native German pronunciation and dual-language translations.

### 6. ✨ Kerala Students' Special Toolkit
- **Interactive 3D Flashcards**: High-yield *Nomen-Verb-Verbindungen* (e.g., *eine Entscheidung treffen*, *zur Verfügung stehen*) with front/back flip animations and Malayalam definitions.
- **Malayalam-Specific Grammar Traps**:
  - Subordinate clause word order (*Nebensatz Word Order: weil, dass, obwohl*).
  - Two-part connectors (*sowohl ... als auch*, *nicht nur ... sondern auch*).
  - Passive alternatives (*Passiversatzformen*).

## 🚀 How to Run Locally

You can run the application directly in any browser:

1. **Directly in Browser**: Double-click [index.html](file:///d:/German%20practice%20app/index.html).
2. **Via Local Server**:
   ```bash
   # Using Python
   python -m http.server 3000

   # Or using Node
   npx serve .
   ```
3. Open `http://localhost:3000` in Google Chrome or Microsoft Edge (recommended for Web Speech API support).
